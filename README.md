Code for: The Cox-Polya-Gamma Algorithm for Flexible Bayesian Inference of Multilevel Survival Models, https://arxiv.org/abs/2402.15060, https://doi.org/10.1093/biomtc/ujaf121

Weibull PH model based on Cox-PG algorithm has been added (25JAN2026).

Weibull-PG PH model derivation has been added (24SEP2026).

Let $\boldsymbol{\eta} = [\alpha_0,\alpha_1,\beta^\top]^\top$ with covariates baseline log-cumulative hazard parameters $\mathbf{m}_i=[1,\log(t_i),\mathbf{x}_i^\top]^\top$. Status $y=1$ denotes the survival event and $y=0$ is right censoring. Poisson regression form of the Weibull PH model is given as $\left[\frac{\alpha_1}{t_i} \exp( \mathbf{m}_i^\top \boldsymbol{\eta} )\right]^{y_i}\exp\left[-\exp( \mathbf{m}_i^\top \boldsymbol{\eta} )\right]$ for the likelihood contribution. The negative binomial or (gamma) frailty likelihood contribution is given as $\left[\frac{\alpha_1}{t_i}\right]^{y_i} \left[\frac{\exp( \mathbf{m}_i^\top \boldsymbol{\eta} -\log(\epsilon) )}{1+\exp( \mathbf{m}_i^\top \boldsymbol{\eta}-\log(\epsilon) )} \right]^{y_i} \epsilon^{y_i} \left[\frac{1}{1+\exp( \mathbf{m}_i^\top \boldsymbol{\eta}-\log(\epsilon) )} \right]^{\epsilon}$. Dropping the constants gives us $\left[\alpha_1\right]^{y_i} \left[\frac{\exp( \mathbf{m}_i^\top \boldsymbol{\eta} -\log(\epsilon) )}{1+\exp( \mathbf{m}_i^\top \boldsymbol{\eta}-\log(\epsilon) )} \right]^{y_i} \left[\frac{1}{1+\exp( \mathbf{m}_i^\top \boldsymbol{\eta}-\log(\epsilon) )} \right]^{\epsilon}$ and the derivations of https://academic.oup.com/biometrics/article/81/3/ujaf121/8258731 are used to derived the Gibbs sampler and HM step for exact MCMC.
